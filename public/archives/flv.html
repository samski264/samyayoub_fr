Fondation Louis Vuitton

INTERACTIVE / TouchDesigner + LeapMotion

FLVX is an interactive mediation installation created for Fondation Louis Vuitton, translating real-time visitor flow into generative visuals on a large-scale projection.

  • I built the real-time interactive system from concept to on-site deployment (prototype → iteration → installation)
  • Designed the interaction layer and visitor-facing controls (hand interaction + tablet navigation)
  • Explored the mediation use-case: turning museum activity into an engaging, readable, evolving visual narrative

Developed during FLV LAB#4, FLVX was designed as a digital mediation device for Fondation Louis Vuitton. The installation captures the museum’s visitor flow in real time and turns it into a generative visual composition projected on the auditorium screen. The system evolves throughout the day based on live inputs, and remains controllable through a contactless hand interface (Leap Motion). A set of tablets provides a “timeline” mode, allowing visitors to explore earlier states and replay the day’s progression.

→ Tech and stacks :

Built in TouchDesigner for a real-time Windows setup, with motion sensing and a projection-ready pipeline.

  • TouchDesigner real-time system (rendering + logic)

  • Leap Motion integration for contactless control

  • Projection mapping / large-screen output workflow

  • Live data ingestion and smoothing to drive generative behaviors

→ Key interaction :

  • Real-time visualization reacting to visitor flow across the day

  • Hand-driven manipulation of the visual model (Leap Motion)

  • Tablet interface to navigate the timeline and replay previous states

  • Large-scale, public-facing output designed for readability at distance
