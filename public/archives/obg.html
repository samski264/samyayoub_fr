Objet Graphique

GENERATIVE / Arduino+impression 3D

As part of the DSAA program, we were asked to design a three-dimensional object connected to our thesis topic. This “Graphic Object” project had to include a digital augmentation.

My proposal for this project was to design a pseudo-machine that users could physically manipulate while experimenting with different types of interfaces. The goal was to initiate a reflection on how interfaces affect the way a machine is used. The object was accompanied by a small user manual to guide the experience.

The structures were 3D-printed using a transparent material to channel light through the object.
